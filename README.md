# 🛡️ Вікторина: Протидія насильству

Інтерактивна веб-вікторина для перевірки знань про протидію насильству з можливістю збереження результатів у Google Таблиці.

## 📋 Опис проекту

Цей проект представляє собою повнофункціональну веб-вікторину на українській мові, присвячену темі протидії насильству. Вікторина допомагає підвищити обізнаність про:

- Види насильства та їх ознаки
- Способи захисту та самооборони
- Куди звертатися за допомогою
- Права жертв насильства
- Юридичні аспекти захисту

## ✨ Основні функції

- 📱 **Адаптивний дизайн** - працює на всіх пристроях (ПК, планшети, смартфони)
- 🎨 **Сучасний інтерфейс** - привабливий дизайн з градієнтами та анімаціями
- 📊 **10 питань** про протидію насильству
- 💾 **Збереження результатів** - автоматична відправка даних у Google Таблиці
- 📈 **Детальна статистика** - відсоток правильних відповідей, час проходження
- 🔄 **Навігація** - можливість повертатися до попередніх питань
- 🎉 **Зворотний зв'язок** - персоналізовані повідомлення в залежності від результату
- 📞 **Корисні контакти** - список гарячих ліній та служб підтримки
- 🔗 **Можливість поділитися** - розповісти друзям про вікторину

## 📥 Встановлення та розгортання

### Крок 1: Клонування репозиторію

```bash
git clone https://github.com/[ваш-username]/viktorina.git
cd viktorina
```

### Крок 2: Налаштування GitHub Pages

1. Перейдіть у налаштування репозиторію на GitHub
2. Знайдіть розділ "Pages"
3. У розділі "Source" оберіть гілку `main` або `master` та папку `/ (root)`
4. Натисніть "Save"
5. Зачекайте кілька хвилин - ваш сайт буде доступний за адресою `https://[ваш-username].github.io/viktorina/`

### Крок 3: Налаштування Google Sheets (опціонально)

Для збереження результатів вікторини у Google Таблиці, дотримуйтесь детальних інструкцій у файлі [GOOGLE_SHEETS_SETUP.md](GOOGLE_SHEETS_SETUP.md).

Коротко:
1. Створіть Google Таблицю
2. Налаштуйте Google Apps Script Web App
3. Скопіюйте URL Web App
4. Вставте URL у файл `script.js` (змінна `GOOGLE_SCRIPT_URL`)
5. Запуште зміни на GitHub

## 💡 Використання

### Для користувачів

1. Відкрийте вікторину у браузері
2. Введіть своє ім'я та email (опціонально)
3. Натисніть "Почати вікторину"
4. Відповідайте на питання, обираючи один з варіантів
5. Використовуйте кнопки "Назад" та "Далі" для навігації
6. Після завершення переглянете свої результати
7. Отримайте зворотний зв'язок та корисні контакти

### Для адміністраторів

Якщо налаштовано інтеграцію з Google Sheets:
- Результати автоматично зберігаються після кожного проходження
- Відкрийте Google Таблицю для перегляду статистики
- Аналізуйте дані: кількість проходжень, середній результат, тощо
- Експортуйте дані для детального аналізу

## 🎨 Налаштування

### Зміна питань

Відредагуйте масив `questions` у файлі `script.js`:

```javascript
const questions = [
    {
        question: "Текст вашого питання?",
        answers: [
            "Варіант 1",
            "Варіант 2",
            "Варіант 3",
            "Варіант 4"
        ],
        correctAnswer: 0  // Індекс правильної відповіді (0-3)
    },
    // Додайте більше питань...
];
```

### Зміна кольорів

Відредагуйте змінні кольорів у файлі `style.css`:

```css
/* Основний градієнт */
background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);

/* Акцентний колір */
color: #667eea;
```

### Зміна контактів

Відредагуйте розділ `.resources` у файлі `index.html`.

## 📊 Аналітика та статистика

При налаштованій інтеграції з Google Sheets ви отримуєте:

- Дата та час проходження
- Ім'я та email учасника (якщо вказано)
- Кількість правильних відповідей
- Відсоток правильних відповідей
- Час проходження вікторини
- Детальні відповіді на кожне питання
