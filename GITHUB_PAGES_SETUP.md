# 🚀 Налаштування GitHub Pages

## Швидкий старт

Щоб опублікувати вашу вікторину на GitHub Pages, виконайте наступні кроки:

### Крок 1: Злийте гілку з main/master

1. Перейдіть у ваш репозиторій на GitHub: `https://github.com/kotr228/viktorina`
2. Натисніть на кнопку "Compare & pull request" для гілки `claude/anti-violence-quiz-site-01N8sPfoXazUxoNifykLnkGC`
3. Створіть Pull Request
4. Змерджте (злийте) його в основну гілку (`main` або `master`)

### Крок 2: Активуйте GitHub Pages

1. Перейдіть у **Settings** (Налаштування) вашого репозиторію
2. У лівому меню знайдіть розділ **Pages**
3. У розділі **Source** (Джерело):
   - **Branch**: оберіть `main` (або `master`, залежно від назви вашої основної гілки)
   - **Folder**: оберіть `/ (root)` - кореневу папку
4. Натисніть **Save** (Зберегти)
5. Зачекайте 1-3 хвилини

### Крок 3: Перевірте сайт

Після активації GitHub Pages, ваш сайт буде доступний за адресою:

```
https://kotr228.github.io/viktorina/
```

**Примітка**: Перше розгортання може зайняти до 10 хвилин.

## Альтернативний метод (без злиття гілок)

Якщо ви хочете опублікувати вікторину з поточної гілки без створення Pull Request:

1. Перейдіть у **Settings** → **Pages**
2. У розділі **Source**:
   - **Branch**: оберіть `claude/anti-violence-quiz-site-01N8sPfoXazUxoNifykLnkGC`
   - **Folder**: оберіть `/ (root)`
3. Натисніть **Save**

## Перевірка статусу розгортання

1. Перейдіть на вкладку **Actions** у вашому репозиторії
2. Ви побачите workflow "pages build and deployment"
3. Зачекайте, поки він завершиться (зелена галочка ✓)
4. Ваш сайт готовий!

## Налаштування власного домену (опціонально)

Якщо у вас є власний домен:

1. У налаштуваннях GitHub Pages знайдіть розділ **Custom domain**
2. Введіть ваш домен (наприклад, `viktorina.example.com`)
3. Налаштуйте DNS записи у вашого провайдера доменів:
   - Для піддомену (subdomain): додайте CNAME запис, що вказує на `kotr228.github.io`
   - Для кореневого домену (apex domain): додайте A записи з IP адресами GitHub:
     ```
     185.199.108.153
     185.199.109.153
     185.199.110.153
     185.199.111.153
     ```
4. Відмітьте "Enforce HTTPS" для безпечного з'єднання

## Оновлення сайту

Коли ви хочете оновити вікторину:

1. Внесіть зміни у файли (index.html, style.css, script.js)
2. Закомітьте зміни:
   ```bash
   git add .
   git commit -m "Опис ваших змін"
   git push
   ```
3. GitHub Pages автоматично оновить сайт через 1-3 хвилини

## Вирішення проблем

### Сайт не відображається

- ✅ Перевірте, чи активовано GitHub Pages у налаштуваннях
- ✅ Переконайтеся, що обрано правильну гілку та папку
- ✅ Перевірте вкладку Actions - можливо, є помилки в процесі розгортання
- ✅ Зачекайте 10-15 хвилин після першого налаштування
- ✅ Спробуйте відкрити сайт в режимі інкогніто (Ctrl+Shift+N)

### Сайт показує 404 помилку

- ✅ Переконайтеся, що файл `index.html` знаходиться в кореневій папці
- ✅ Перевірте правильність URL: `https://kotr228.github.io/viktorina/`
- ✅ URL чутливий до регістру - переконайтеся, що використовуєте правильний регістр

### Стилі не застосовуються

- ✅ Перевірте консоль браузера (F12) на наявність помилок
- ✅ Переконайтеся, що файли style.css та script.js знаходяться в тій же папці, що й index.html
- ✅ Очистіть кеш браузера (Ctrl+Shift+R або Ctrl+F5)

### Зміни не відображаються

- ✅ Зачекайте 2-3 хвилини після push
- ✅ Очистіть кеш браузера
- ✅ Перевірте вкладку Actions - чи завершилося розгортання

## Додаткові налаштування

### Налаштування HTTPS

GitHub Pages автоматично надає безкоштовний HTTPS сертифікат. Переконайтеся, що опція "Enforce HTTPS" увімкнена в налаштуваннях Pages.

### SEO та метатеги

Для кращої видимості в пошукових системах можна додати файл `robots.txt` та метатеги в `index.html` (вже включені в шаблон).

### Аналітика відвідувачів

Для відстеження відвідувачів можна додати:
- Google Analytics
- Яндекс.Метрика
- Простіші аналітичні інструменти
