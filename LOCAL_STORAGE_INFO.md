# 💾 Локальне збереження результатів

## Що це таке?

Вікторина тепер **автоматично зберігає всі результати локально** в браузері користувача за допомогою localStorage. Це означає, що:

- ✅ **Працює без налаштування** - не потрібно налаштовувати Google Sheets
- ✅ **Швидко** - результати зберігаються миттєво
- ✅ **Безпечно** - дані зберігаються тільки у вас в браузері
- ✅ **Зручно** - є адмін-панель для перегляду статистики

## 📊 Адмін-панель

Відкрийте файл **admin.html** у браузері або перейдіть за посиланням на сайті для перегляду:

- Загальна статистика (кількість проходжень, середній бал, тощо)
- Детальні результати всіх користувачів
- Експорт даних у JSON або CSV формат
- Можливість очистити всі результати

### Як відкрити адмін-панель:

```
Просто відкрийте файл admin.html у браузері
```

## 📥 Експорт даних

В адмін-панелі доступні дві опції експорту:

### 1. Експорт у JSON
- Повний експорт всіх даних
- Включає детальні відповіді на кожне питання
- Зручно для програмної обробки

### 2. Експорт у CSV
- Таблиця з основними даними
- Можна відкрити в Excel або Google Sheets
- Зручно для аналізу та звітів

## 🔄 Подвійне збереження

Вікторина підтримує **два способи збереження одночасно**:

1. **Локальне збереження** (працює завжди)
   - Результати зберігаються в браузері
   - Доступні через admin.html
   - Не потребує налаштування

2. **Google Sheets** (опціонально)
   - Якщо налаштовано за інструкцією GOOGLE_SHEETS_SETUP.md
   - Дані автоматично відправляються і в Google Таблицю
   - Централізоване зберігання для множинних користувачів

## ⚠️ Обмеження локального збереження

**Важливо знати:**

- Дані зберігаються **тільки в одному браузері** на одному пристрої
- При очищенні кешу браузера дані можуть бути видалені
- Різні користувачі на різних пристроях не бачать результати один одного
- Обмеження: близько 5-10 МБ даних (достатньо для тисяч проходжень)

## 💡 Рекомендації по використанню

### Для особистого використання:
- Локального збереження цілком достатньо
- Використовуйте admin.html для перегляду своєї статистики
- Періодично експортуйте дані як резервну копію

### Для публічної вікторини (багато користувачів):
- **Обов'язково налаштуйте Google Sheets** за інструкцією
- Локальне збереження все одно працюватиме як backup
- Використовуйте Google Sheets для централізованої аналітики

### Для організацій/шкіл:
- Налаштуйте Google Sheets для збору даних
- Дайте доступ до Google Таблиці тільки адміністраторам
- Регулярно аналізуйте статистику в Google Sheets

## 🔐 Конфіденційність

**Локальне збереження:**
- Дані НЕ передаються на зовнішні сервери
- Дані НЕ збираються розробниками
- Дані зберігаються тільки у браузері користувача
- Тільки користувач має доступ до своїх даних

**Google Sheets (якщо налаштовано):**
- Дані відправляються у ВАШУ Google Таблицю
- Тільки ВИ маєте доступ до цих даних
- Google Apps Script працює під вашим обліковим записом

## 🛠️ Технічні деталі

### localStorage
```javascript
// Результати зберігаються за ключем:
localStorage.getItem('quiz_results')

// Формат: JSON масив об'єктів
[
  {
    "timestamp": "2025-11-25T10:30:00.000Z",
    "name": "Іван",
    "email": "ivan@example.com",
    "correctAnswers": 8,
    "totalQuestions": 10,
    "percentage": 80,
    "timeSpent": 145,
    "answers": [...]
  },
  ...
]
```

### Розмір даних
- Один результат: ~2-3 КБ
- 100 результатів: ~200-300 КБ
- 1000 результатів: ~2-3 МБ

## ❓ Часті питання

**Q: Чи можу я видалити локальні дані?**
A: Так, натисніть "Очистити всі" в адмін-панелі або очистіть кеш браузера.

**Q: Чи працює локальне збереження на телефоні?**
A: Так, працює на всіх сучасних браузерах (Chrome, Safari, Firefox, тощо).

**Q: Чи можу я переглянути результати інших користувачів?**
A: Ні, локальне збереження показує тільки результати з цього браузера. Для централізованого збору використовуйте Google Sheets.

**Q: Що краще - локальне збереження чи Google Sheets?**
A: Залежить від мети:
- Особисте використання → локальне збереження
- Публічна вікторина → Google Sheets
- Обидва варіанти можна використовувати одночасно

**Q: Чи зберігаються дані після перезавантаження браузера?**
A: Так, дані зберігаються постійно до очищення або видалення.

## 📞 Підтримка

Якщо виникли проблеми:
1. Перевірте консоль браузера (F12) на наявність помилок
2. Переконайтеся, що localStorage увімкнено в браузері
3. Спробуйте експортувати дані перед очищенням
4. При потребі налаштуйте Google Sheets як альтернативу
